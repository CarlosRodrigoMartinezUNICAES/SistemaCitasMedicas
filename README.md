# Sistema de Citas Médicas 🩺📅

Pequeña app para gestionar citas clínicas — frontend con React + Vite y esquema de base de datos en MariaDB. Visual, simple y listo para expandir.

## Características
- ✨ Interfaz moderna (React + Vite)
- 🗓️ Gestión de citas, pacientes y médicos
- 🗄️ Esquema SQL para MariaDB incluido
- 🎨 Tipografía Inter para una experiencia visual profesional

## Tecnologías
- ⚛️ React
- ⚡ Vite
- 🐬 MariaDB (script en repo)
- 🎨 Inter Font (Google Fonts)

## Rápido arranque
1. Abrir carpeta cliente:
   ```bash
   cd client
   ```
2. Instalar y correr:
   ```bash
   npm install
   npm run dev
   ```

## Tipografía
El proyecto utiliza la fuente **Inter** de Google Fonts para proporcionar una experiencia visual moderna y profesional, similar a Figma. La fuente se carga automáticamente y está configurada como la fuente principal en todo el proyecto.
