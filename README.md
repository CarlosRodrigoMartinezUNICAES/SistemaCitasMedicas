# Sistema de Citas Médicas 🩺📅

Pequeña app para gestionar citas clínicas — frontend con React + Vite y esquema de base de datos en MariaDB. Visual, simple y listo para expandir.

Características
- ✨ Interfaz moderna (React + Vite)
- 🗓️ Gestión de citas, pacientes y médicos
- 🗄️ Esquema SQL para MariaDB incluido

Tecnologías
- ⚛️ React
- ⚡ Vite
- 🐬 MariaDB (script en repo)

Rápido arranque
1. Abrir carpeta cliente:
   - cd client
2. Instalar y correr:
   - npm install
   - npm run dev
